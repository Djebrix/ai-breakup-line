[Dear Human: The AI Breakup Line on make.fun](https://make.fun/bounty/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16)

`main.py` (stdlib only, no network) writes the line to `entry.txt` in
`ENTRY_OUTPUT_DIR` (default `/output`). The line is at most 200 characters.
